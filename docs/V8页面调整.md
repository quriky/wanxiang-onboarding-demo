# V8 页面调整

活动入口位于左侧积分余额上方和充值页顶部。活动海报可点击进入新手任务；已开通时显示查看任务。充值页取消渐变按钮，保留金额选择、兑换比例、自定义金额和模拟充值，将辅助介绍折叠。

任务页使用白底列表，只突出可领积分、三组各三行任务和领取按钮。详细规则、积分记录、演示工具默认收起。展开演示工具才显示逐项“模拟完成”开关。按使用日解锁、提前完成、补领期、到期和防重复领取规则未更改。

海报生成原图在 assets/activity/new-user-banner.png。网页与海报均为方案演示；没有真实支付和发奖。上传三个 HTML 和整个 assets 文件夹即可更新演示。海报提示词见同目录《海报制作说明.md》。
