# V9 每日任务与操作指引

## 日期按钮

第 1 天／第 2 天／第 3 天三个按钮切换，一次只显示三行任务。按钮展示对应日期的可领积分、待解锁或已领完状态。未来日期可以预览并提前完成普通任务；切换标签本身不累计日期或解锁积分。支持左右方向键及 Home / End。

三个日期表示购买后前 7 天内累计的三个不同使用日期，不要求连续。购买当天为第一天；第二、第三个不同日期回来后自动记录签到资格，客户点“签到领奖”才发放模拟积分。奖励可单独领，也可通过一键领取获取所有当前符合条件的奖励。重复领取不加积分。

## 去完成

每项普通任务的“去完成”先弹出步骤说明，可关闭或稍后再做。开工任务先进入百应应用详情，按当前订阅、下载状态继续，真正进入开工网页演示后才完成该任务。充值页的应用入口也先进入详情。

看案例任务跳到案例列表并说明如何选作品。录用、创建、自动化和资料引用跳入对应栏目，并显示任务指引和随操作变化的顶部提示。指导仅说明操作，不自动代替确认录用、创建员工、发送对话或保存自动化。主动点击任务指引会进入该任务的操作流程，不自动遍历其他栏目。

任务目的地的弹窗参数使用后即清除，刷新不循环弹出。顶部可再次查看任务指引，也可关闭提示栏。普通新手的首次分栏目教学仍保留。

## 站内提醒

首次礼包介绍只出现一次，且避开欢迎弹窗和正在进行的教学。客户已经在任务页时，不重复弹首次礼包介绍。

已开通客户在有待领积分或未完成任务时，每个活动自然日最多展示一次提醒。关闭或点击“稍后再看”后，当天刷新、返回或切换百应与开工不重复。签到待领时优先进入对应签到日期；第 8—15 天只提醒任务期内已取得领取资格的奖励。没有可领取奖励时不做补领提醒；第 16 天以后不继续推送该活动提醒。

主动进入任务操作时会避开额外提醒，不打断操作；演示工具中的“预览客户提醒”可手动重看。

仅做站内弹窗模拟，没有微信、短信、邮件或客服主动联系，没有真实定时消息。正式触达渠道、授权、发送频率和服务端状态需要后续接入。

## 演示与上线

9.9 元、30 天权益、200 基础积分与最高 600 任务积分仍是示例。7 天做任务和解锁、15 天补领、16 天未领奖励过期的规则不变。本次没有真实支付、发奖、模型调用、录用或第三方授权。
